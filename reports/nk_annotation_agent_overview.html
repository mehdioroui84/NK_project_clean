Optional step 03b

How the annotation agent works

Evidence-first refinement: the agent reads cluster evidence, proposes a pipeline-safe label, and records why it did or did not recommend a change.

1. Evidence package

Manual composition, top DE genes, curated marker programs, and tissue, dataset, assay context are bundled per cluster.

2. LLM annotation pass

The model scores confidence, ambiguity, and technical concern while judging whether the current label is biologically supported.

3. Refinement loop

Clusters needing review can trigger pairwise DE and distance-prioritized checks before another annotation pass.

4. Approved mapping

The output remains compatible with script 04: one refined label per Leiden cluster, plus review notes and alternatives.

Key principle: the agent does not silently rewrite the training target. It chooses an approved refined label, then separately flags uncertainty, review reasons, and possible alternative names.
Optional mode: discovery-first hides the initial draft label in the first pass to reduce anchoring.
Reviewable outputs

What the agent produces, and how we keep it honest

The agent is a structured reviewer, not an oracle: every claim is exported for human inspection before labels are applied downstream.

Pipeline-safe label

candidate_refined_label is restricted to the approved refined-label vocabulary used by script 04 and SCANVI.

Reasoning trace

Each cluster gets evidence summaries, concerns, confidence, ambiguity, technical concern scores, and suggested checks.

Review flags

Low confidence, high technical concern, pairwise disagreement, or alternative-label suggestions trigger manual review.

Safeguards against over-calling novelty

  1. New labels require multiple evidence layers, not one marker or latent-space distance alone.
  2. Tissue, dataset, assay, stress, and ambient-RNA signals are treated as technical concerns first.
  3. Pairwise DE audits nearby or confusing clusters before revising a label.
  4. Alternative names stay separate from the training label until human review approves them.
